🛠️ What is my StarDance Project?

Project codename: "StarDance-Sync-v1.ino"

For the Hack Club StarDance competition, I wanted to combine sound-reactive hardware with rhythm synchronization! It's an ESP32 microcontroller hooked up to 60 addressable WS2812B LEDs and an electret microphone that pulses colors to the beat of whatever song is playing.

🧠 Brains

ESP32 NodeMCU (bought with pocket money)

💡 Lights

60x WS2812B RGB NeoPixel Strip

🎧 Sensor

MAX9814 Audio Auto-Gain Mic module

💻 Code

C++ on Arduino IDE + FastLED library


⚠️ Things that went wrong while building this:

  • Accidentally reversed 5V and GND on day 1 (smelled like burnt plastic, RIP first diode 🪦)
  • Code crashed whenever the bass hit too hard (fixed by adding a random 1000uF capacitor I found in my drawer)
  • Forgot semicolon on line 42 and stared at screen for 45 minutes
